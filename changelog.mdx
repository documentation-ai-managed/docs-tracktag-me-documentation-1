## Release History

<Update label="2024-10-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Added support for AAC audio format processing
- Introduced advanced metadata embedding capabilities
- Enhanced batch processing with progress indicators

## Improvements

- Improved audio quality preservation during watermarking
- Faster processing speeds for large files
- Better compatibility with macOS Sonoma

</Update>

<Update label="2024-09-20" description="v2.0.0" tags={["breaking", "feature"]}>

## New Features

- Complete UI redesign with modern interface
- New watermarking algorithms including spread spectrum
- API integration for web applications

## Breaking Changes

- Minimum system requirements updated to macOS 10.15+
- Configuration file format changed (migration tool provided)

</Update>

<Update label="2024-08-10" description="v1.5.0" tags={["feature", "bugfix"]}>

## New Features

- Batch processing for multiple audio files
- Custom watermark strength settings
- Export verification reports

## Bug Fixes

- Fixed compatibility issues with Windows 11
- Resolved audio quality degradation in some file types
- Corrected metadata extraction errors

</Update>
